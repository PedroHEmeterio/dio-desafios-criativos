# dio-desafios-criativos
Repositório usado para colocar desafios criativos da DIO.

Você é um assistente de TI e precisa analisar as solicitações feitas por usuários dentro do nosso sistema de HelpDesk e identificar quais são as maiores solicitações (problemas de sistema, problemas de hardware, problemas de rede e etc). 

A análise será usada pelo coordenador da equipe, juntamente com diretor da empresa para gerar indicadores de maiores solicitações e quem mais responde os chamados, com intuito de gerar bonificações para a equipe.

A entrega deve conter uma tabela por membro da equipe de TI com colunas de total de chamados e tipos de chamados e suas quantidades. 

A análise será boa se for simples e com informações sucintas para evitar muito tempo de leitura e consequentemente o desinteresse dos analistas.

Contexto: Estou trabalhando indicadores de trabalho com base em nosso sistema de HelpDesk

Dados disponíveis: A base contém: nome do funcionário, tipos de chamados atendidos, tempo de atendimento (SLA).

Critérios de análise: A IA deve classificar os chamados por funcionário e seus tipos de chamados

Cuidados e restrições:

    Use apenas os dados fornecidos.
    Não invente números, causas ou conclusões.
    Não exponha dados pessoais ou sensíveis.
    Se houver informação insuficiente, indique a limitação.
    Use linguagem e direta.
